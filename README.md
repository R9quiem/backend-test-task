# Сервис отслеживания цен криптовалют

## О проекте

В тестовом задание был реализован REST API для управления списком отслеживаемых криптовалют,
получения последней сохранённой цены и истории измерений.

Для начала отслеживания монеты нужен всего лишь ID CoinMarketCap этой монеты,
символ и название подтянется с их api.


## Стек и требования

Node.js, TypeScript, Express, SQLite (ORM не был использован в проете согласно тз),
axios, Jest и Supertest.

Для запуска нужны:
- Node.js 24.15.0 или новее в ветке 24.x;
- npm;
- API-ключ CoinMarketCap.

## Установка и запуск

```
git clone https://github.com/R9quiem/backend-test-task.git
cd backend-test-task
npm ci
```

Создайте файл `.env` и заполните ключи в `.env`.

Сборка и запуск:

```powershell
npm run build
npm start
```

Запуск для разработки:

```powershell
npm run dev
```

API будет доступен по адресу `http://localhost:3000`.
Файл БД и таблицы создаются автоматически.

## Настройки

Настройки передаются через `.env`.

- `PORT` - порт HTTP-сервера. По умолчанию `3000`.
- `API_KEY` - ключ доступа к собственному API. Обязателен.
- `COINMARKETCAP_API_KEY` - ключ CoinMarketCap. Обязателен.
- `DATABASE_PATH` - путь к файлу SQLite. По умолчанию `./data/app.sqlite`.
- `QUOTE_CURRENCY` - единая валюта цен. По умолчанию `USD`.
- `SYNC_INTERVAL_MS` - пауза между синхронизациями в миллисекундах. 

- `.env` и файлы БД исключены из Git.

## API

Все запросы требуют заголовок:

```http
Authorization: Bearer <API_KEY>
```

| Метод | Маршрут | Назначение |
|---|---|---|
| POST | `/cryptocurrencies` | Добавить монету |
| GET | `/cryptocurrencies` | Получить список |
| GET | `/cryptocurrencies/:id` | Получить одну запись |
| PATCH | `/cryptocurrencies/:id` | Изменить название |
| DELETE | `/cryptocurrencies/:id` | Удалить монету и её историю |
| GET | `/cryptocurrencies/:id/price` | Получить последнее измерение |
| GET | `/cryptocurrencies/:id/history` | Получить историю |

`:id` в маршрутах - внутренний идентификатор записи в БД.

Для добавления Bitcoin отправьте POST с `Content-Type: application/json`:

```json
{
  "coinmarketcapId": 1
}
```

Название и символ будут получены из CoinMarketCap.
При недоступности источника запись не создаётся.

Пример получения истории:

```http
GET /cryptocurrencies/1/history?limit=20&offset=0
```

Записи возвращаются от новых к старым.
`limit` - от 1 до 100, по умолчанию 20.
`offset` - от 0, по умолчанию 0.

Спецификация API: [OpenAPI 3.0](docs/openapi.yaml).

Для просмотра откройте файл в [Swagger Editor](https://editor.swagger.io/).

## Синхронизация цен

Первое обновление выполняется при запуске сервера.
Следующее начинается через `SYNC_INTERVAL_MS` после завершения предыдущего.

Каждая успешная синхронизация сохраняет измерения и обновляет время
последнего успешного получения цены одной транзакцией.

Эндпоинты цены и истории читают SQLite и не обращаются к CoinMarketCap.
История накапливается с первого успешного обновления каждой монеты.
Во время остановки сервиса измерения не собираются.

При `SIGINT` или `SIGTERM` приложение прекращает новые запуски,
дожидается активной синхронизации и HTTP-запросов, затем закрывает БД.

## Тесты

Запуск всех тестов:

```powershell
npm test
```

Тесты проверяют crud, авторизацию, выдачу цен и истории,
сохранение измерений, транзакции, фоновую синхронизацию.

Используются временные файловые БД и подменный CMC-клиент.
Настоящий API-ключ и сетевые запросы не требуются.
